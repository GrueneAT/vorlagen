01Strategy

Strategy summary

Kleine, datengetriebene Änderung: das videos-Array in site/src/data/videos.ts wird von vier Alt-Aufnahmen (alle mit legacyDesign: true) auf zwei neue Scribus-Videos umgestellt — ohne legacyDesign und ohne belastbare duration. Der Legacy-Hinweis-Callout in VideoGrid.astro ist bereits bedingt gebaut (hasLegacyDesign = videos.some(v => v.legacyDesign)) und verschwindet automatisch, sobald kein Eintrag mehr das Flag trägt — keine Markup-Änderung nötig.

Zwei Punkte sind nicht offensichtlich aus dem Issue-Text, aber code-verifiziert: .app-video-grid nutzt repeat(auto-fill, minmax(220px, 1fr)), kein festes Vier-Spalten-Grid — mit nur zwei Karten bleiben auf breiten Viewports leere Grid-Spuren stehen. Und tests/unit/test_site_anleitung_content.py ist hart auf die vier alten IDs gekoppelt; eine Testfunktion ist absichtlich so gebaut, dass sie beim Wegfall aller legacyDesign-Flags fehlschlägt, mit der expliziten Anweisung, sich selbst zu entfernen.

  • Datenänderung reicht für den Hinweis-Wegfall.

    Kein Component-Code nötig — hasLegacyDesign ist bereits korrekt aus dem Array abgeleitet.

  • auto-fill lässt bei zwei Karten Lücken.

    Fix: auto-fill → auto-fit in app.css, plus moderate Max-Breite pro Karte.

  • Guard-Test bricht CI trotz grünem Build.

    npm run build deckt tests/unit/test_site_anleitung_content.py nicht ab — beide müssen laufen.

  • duration nicht verlässlich ermittelbar.

    Feld ist optional und ungetestet — weglassen statt raten.

02Flow

Task flow & dependencies

Schritt 1 videos.ts ersetzen Zwei neue Einträge, kein legacyDesign, kein duration.
Schritt 2 Grid-CSS anpassen app.css: auto-fill → auto-fit, Max-Breite ergänzen.
Schritt 3 Guard-Test aktualisieren EXPECTED_VIDEO_IDS setzen, Legacy-Test entfernen.
Schritt 4 Verifikation npm run build + pytest tests/unit/ müssen beide grün sein.

03Decisions

Key decisions & options

Grid-Layout bei nur zwei Karten

Chosen

grid-template-columns: repeat(auto-fit, minmax(220px, 320px)) — kollabiert leere Spuren, verteilt den Platz auf die realen Karten, ohne dass sie randlos über die volle Breite gezogen werden.

Feste Spaltenzahl per JS/Zähl-Logik — Overkill für ein statisches Zwei-Item-Array.

Umgang mit dem Legacy-Hinweis-Markup

Chosen

Callout-Block in VideoGrid.astro unverändert lassen — hasLegacyDesign wird automatisch false, sobald kein Eintrag mehr legacyDesign: true trägt. So sieht es das Issue vor.

Markup aktiv entfernen — unnötiger Diff, widerspricht der im Code dokumentierten Absicht.

duration für die neuen Videos

Open

Weglassen — via YouTube-oEmbed nicht ermittelbar, Feld ist optional und rein kosmetisch (VideoGrid.astro rendert das Duration-Badge nur, wenn gesetzt).

Wert schätzen/raten — keine verlässliche Quelle gefunden, würde eine falsche Angabe auf die Karte bringen.

Guard-Test test_legacy_design_notice_matches_the_data

Chosen

Entfernen — die Testfunktion selbst instruiert das in ihrer pytest.fail-Meldung, sobald kein Video mehr als legacyDesign markiert ist.

Test unverändert lassen — würde CI hart rot machen (pytest tests/unit/), obwohl npm run build grün bleibt.
